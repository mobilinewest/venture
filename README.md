# Учёт клиентов

Простая программа для учёта клиентов (мини-CRM) с веб-интерфейсом.
Написана на Python, работает **без внешних зависимостей**: нужна только стандартная библиотека
(Python 3.9+). Данные хранятся в одном файле SQLite.

## Возможности

- Карточка клиента: ФИО, телефон, email, компания, адрес, статус, теги, заметки
- Статусы: потенциальный / активный / неактивный
- История взаимодействий: заметки, звонки, встречи, письма, **заказы** и **оплаты**
- Автоматический расчёт по каждому клиенту: сумма заказов, оплачено, баланс (долг или переплата)
- Сводка: число клиентов, общая выручка, оплаты, общая задолженность и число должников
- Поиск по имени, телефону, email, компании, тегам и заметкам (включая кириллицу без учёта регистра)
- Фильтры по статусу и тегу, сортировка (по имени, по дате, по сумме заказов, по последнему контакту)
- Экспорт в CSV (открывается в Excel) и импорт из CSV
- Светлая и тёмная тема, работает на телефоне

## Запуск

```bash
python3 -m clients
```

Браузер откроется на http://127.0.0.1:8000/. Данные сохраняются в `clients.db` в текущей папке.

Параметры:

```bash
python3 -m clients --port 8080 --db /путь/к/базе.db --no-browser
python3 -m clients --host 0.0.0.0   # доступ из локальной сети (без авторизации — только в доверенной сети!)
```

## Импорт из CSV

Первая строка — заголовки. Распознаются колонки `Имя`, `Телефон`, `Email`, `Компания`, `Адрес`,
`Статус` (`lead`/`active`/`inactive`), `Теги`, `Заметки` (или те же имена на английском: `name`, `phone`, …).
Разделитель `;` или `,` определяется автоматически. Файл, выгруженный экспортом, можно загрузить обратно.

## Структура

```
clients/
  __main__.py      — запуск из командной строки
  db.py            — хранение данных (SQLite), валидация, статистика
  server.py        — HTTP-сервер и JSON API, экспорт/импорт CSV
  static/index.html — веб-интерфейс
tests/test_clients.py
```

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/clients?q=&status=&tag=&sort=` | список клиентов |
| POST | `/api/clients` | создать клиента |
| GET / PUT / DELETE | `/api/clients/{id}` | получить (с историей) / изменить / удалить |
| POST | `/api/clients/{id}/interactions` | добавить запись в историю |
| DELETE | `/api/interactions/{id}` | удалить запись |
| GET | `/api/stats` | сводная статистика и список тегов |
| GET | `/api/export.csv` | экспорт (учитывает фильтры) |
| POST | `/api/import` | импорт CSV (тело запроса — текст файла) |
